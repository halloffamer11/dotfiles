# Media operating procedure

## Inspect

Inventory every available photo and video. Detect duplicates and assess
sharpness, lighting, orientation, framing, reflections, personal information,
serial exposure, and coverage of visible defects. Record what each file
supports; a still image does not establish cleanliness, functionality, or an
unseen accessory. Before using or translating a visible numeric label claim,
inspect it at sufficient or original detail and recheck the exact transcribed
value against the image. Apply the file's embedded orientation before cropping
or measuring; a crop computed on un-oriented pixels lands on the wrong region.

## Derive

Create a derivative only when it improves useful viewing or compatibility.
Permitted changes include conversion, rotation, crop, exposure correction,
compression, and normalization. Preserve originals unchanged and trace every
derivative to its source, including the transformation and any material
limitation. Do not make a derivative that conceals damage, removes meaningful
context, or materially changes product appearance.

## Select

Order the selected media to make truthful evaluation easy: a clear hero image;
overall condition; important angles; functional components; included
accessories; safe model evidence; and honest defect disclosure. Prefer a
smaller, comprehensible set over repetitive files. Avoid publishing personal
information or unnecessary serial numbers; retain sufficient safe model evidence
to support identification.

## Improve

Recommend an additional seller photo or test only when it reduces a
consequential buyer uncertainty identified by product or market research, such
as a model-confusing label, a needed accessory, a visible defect, or a feature
that materially affects value or safe use. State the uncertainty and the
specific evidence that would resolve it. Do not request extra work merely to
make the listing look more polished.

## Record

Write source and derived paths in the listing record. Write the selected paths
in display order, with a short note for each file’s evidence. Add rejection
notes for duplicates, weak framing, privacy risk, ambiguity, or uncovered
limitations, so future revisions remain traceable.

## Quality

Favor clarity and trust over excessive editing. Keep visible wear and defects
honest, and do not use processing to conceal damage or materially alter product
appearance. Videos may be used as evidence or to extract useful stills when
supported; publication of a video is never required.

## Tool freedom

Choose any method that achieves these outcomes. This procedure requires no
particular command, library, editor, converter, or output format.
