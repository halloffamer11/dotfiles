## Subscription accounting rules

**OpenAI (Codex CLI):** Plus/Pro/Business meter against a rolling 5-hour window plus an unpublished
weekly cap; both are token/credit-based, not fixed message counts — "tasks that look similar can
consume different amounts of your allowance" per OpenAI's own pricing page. Model choice drives the
listed per-5h message estimates (10–100 for Sol, 25–200 Terra, 250–2,000 Luna, 5–45 Astra on Plus;
Pro multiplies by 5x/20x). Context size, tool use, retrieval, and caching also change consumption;
OpenAI does not publish a specific multiplier tied to reasoning-effort level alone. The 5-hour limit
for Plus/Business was removed 2026-07-12 and restored 2026-08-25; Pro $100/$200 tiers were reported
(secondary sources) to remain exempt from the 5-hour limit as of that date — UNVERIFIED against an
OpenAI primary source for the exemption's current status.

**xAI (Grok CLI / SuperGrok):** Since June 2026, xAI replaced per-feature daily caps with one shared
weekly compute pool across Chat, Imagine, Voice, Build, and API, shown as a percentage in
Settings → Usage, with a per-account weekly reset time. xAI has not published per-model or
per-effort-level weighting inside that pool. It is unconfirmed whether the Grok CLI specifically
draws from the "Build" bucket, the "API" bucket, or blends both — flagged as an open question below.

**Google (agy / Antigravity):** Antigravity meters Gemini-family models on a weekly limit that tops
up every 5 hours on paid plans (Google AI Pro / Ultra); the free tier resets only once a week with no
5-hour top-up. Claude and GPT models available inside Antigravity run on a separate, fixed-rate quota
pool, kept apart from the Gemini pool because of third-party capacity constraints — so a Claude or
GPT call through agy does not draw down Gemini quota or vice versa. Google AI Ultra gets priority
traffic and the highest limits; exact numeric caps for either tier are not published.

**Anthropic (Claude Code):** Pro and Max plans meter against a rolling 5-hour session window and a
weekly window that applies across all models (one shared pool with Claude chat and Cowork). Max plans
add a second, Opus-specific weekly budget on top of the all-models weekly budget. Multiple
third-party sources (not Anthropic-primary) report that since 2026-09-01 Fable 5.1 usage on Max
counts against up to 50% of the weekly limit before falling back to pay-as-you-go usage credits —
this specific figure is UNVERIFIED against an Anthropic-authored page in this pass. Reasoning effort
directly affects consumption: extended-thinking tokens bill as output tokens, effort level is
adjustable via `/effort`, and Fable models cannot disable extended thinking at all (confirmed on
Anthropic's own Claude Code costs page).

## Usage probes

- **Anthropic:** No official `claude usage` CLI command or public per-account usage-remaining API.
  In-session `/usage` TUI is official but not scriptable across accounts. Community MCP servers
  (e.g. `claudeusage-mcp`) read the locally stored OAuth token and call an undocumented Anthropic
  usage endpoint — not vendor-sanctioned. The documented **Rate Limits API**
  ([platform.claude.com/docs/en/manage-claude/rate-limits-api](https://platform.claude.com/docs/en/manage-claude/rate-limits-api))
  is org/workspace rate-limit configuration for Admin API keys, not a personal subscription-usage
  probe. Per-response `anthropic-ratelimit-*` headers exist but only reflect API-key rate limits, not
  subscription session/weekly usage.
- **OpenAI:** `/status` inside the Codex CLI session and the ChatGPT usage panel in Settings are the
  documented ways to check remaining Codex allowance; no separate public REST endpoint for remaining
  ChatGPT-subscription Codex usage was found.
- **xAI:** Settings → Usage in the ChatGPT-equivalent SuperGrok UI shows percentage used and reset
  time; no documented API/CLI endpoint for programmatic remaining-usage checks was found.
- **Google:** The official `/usage` (aka `/quota`) slash command inside agy is documented. An
  undocumented local RPC, `/exa.language_server_pb.LanguageServerService/GetUserStatus`, served by
  the running `agy` process over local gRPC/Connect on 127.0.0.1, is used by community tools
  (`antigravity-usage`, `opencode-antigravity-quota`) to read quota fractions and reset timestamps —
  this is reverse-engineered, not an official public API.

- No published tokens-per-second or latency figures found for any of: gpt-5.6/gpt-6-astra, grok-4.6,
  gemini-3.8-flash. Only Anthropic's Opus 5 Fast Mode has a stated relative-speed figure (~2.5x).
