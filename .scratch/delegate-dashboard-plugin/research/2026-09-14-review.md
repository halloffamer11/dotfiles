## Lead adjudication — Spec

1. Fixed in `140f23d`: row state includes catalog Order provenance; `p`/`g`
   markers and a legend make it visible. Public model tests cover the sources.
2. Not reverted. Rejecting a merged Class floor above its ceiling tightens
   handling of invalid policy; it does not change the valid-input contract.
   The complete-proposal validator requires this check. The Order display in
   `catalog.py show` is explicitly requested in ticket 04. All existing valid
   fixtures pass. This is a documented compatibility distinction, not a claim
   that every formerly accepted invalid document behaves identically.
3. Clarified in `140f23d`: `g` means global Order or a fallback derived from
   global Order/name. A displayed fallback position need not be a literal
   value in the global file; the file remains its input provenance.
4. Fixed in `3058e23` and `1e6fb37`: rank and dashboard use the same
   `meter_observations()` validity rule. Valid wrapped and legacy map formats
   agree. A malformed observation makes the whole document unknown for every
   caller. This intentionally replaces the old ranker's partial use of invalid
   documents. Public Class/Tier/dashboard tests cover mixed-invalid caches.
5. Fixed in `c23c47b`: saves reread the original global files before validation.
   Tests cover a newly disabled lane, changed merged Class constraint, failed
   global reload, and a successful valid save. `1be2e67` replaces an internal
   spy with a public-state assertion. The final check/rename window is not a
   filesystem lock; that limit remains documented.

Additional lead finding: nonfinite floats and huge integers could bypass or
crash dashboard Meter validation. Grok fixed this in `2ddbdbe`; the final shared
validator retains the fix and tests strict JSON output.

Count: 5 reported findings; 4 addressed or clarified, 1 adjudicated without a
revert. The worst issue was a stale-global save creating invalid Project order;
fixed. Human predictability and usability remain ticket 09's open verdict.
